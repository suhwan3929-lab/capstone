# `tipover_monitor.py`

UI와 분리된 전도 판정 FSM입니다.

```text
정상 → 충격 ≥ 2.8 g
     → 충격 후 1~3초 표본 중 기울기 ≥ 60°가 75% 이상
     → 움직임 5초 관찰
     → 사용자 응답 10초 대기
     → 확정·신고
```

취소 명령은 판정 중 어느 단계에서도 처리합니다. 자세 회복 또는 시간 간격을 둔 움직임 2회가 확인되면 해제합니다. SOS는 FSM을 건너뛰며, 신고는 사고당 한 번만 전송합니다.

공개 API:

- `start()` / `stop()`
- `submit(command)`
- `snapshot()`
- `step(imu, gps)`: 가상 시계 기반 테스트·재생

수정 후에는 14개 FSM 테스트를 반드시 실행합니다. IMU가 무효일 때 상태가 진행되거나, 취소가 유실되거나, 같은 사고가 중복 신고되면 안 됩니다.
