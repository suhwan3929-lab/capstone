# 2026-11-06 실기 통합 진행 현황

**현재 상태:** GPS·IMU 개별 검사와 기존 웹훅 문자/실제 GPS 지도 수신을 확인했다. Pi 안전서비스는 재부팅 후에도 active였다. 화면은 같은 전원에서 USB 장치를 제거하고 켠 뒤 복구됐으며, **전원 원인 해결은 사용자 요청으로 보류**한다.

[후속 트러블슈팅 18개 사례](troubleshooting_history_20261106.md) · [접고 펼치는 HTML](troubleshooting_history_20261106.html) · [이전 11월5일 현황](progress_2026-11-05.md)

## 확인된 범위

- **네트워크/라이다:** 전용 유선 Jetson192.168.10.1→Pi192.168.10.2, 실제 양쪽 점군·재연결 복구 및 Jetson 자동 시작을 확인했다. 현재 USB 제거 뒤의 전체 센서 상태를 새로 확인한 것은 아니다.
- **GPS:** 고정 포트/115200bps/NMEA 수신, 실제 DGPS와 지도 메시지 수신. 외부 위치 오차와 RTK 고정 성능은 미검증이다.
- **IMU:** 기존 수신기+V6 송신기, /dev/walker_imu/921600/wireless/CH100·ID0, 움직임·약1g·±16g/±2000dps 설정·송신기 재시작 유지·USB 재연결 복구를 확인했다.
- **GUI/알림:** 지도 차단 처리 수정 후 GUI 동작 보고, 기존 웹훅 비사고 문자와 실제 GPS 지도 이미지·링크 수신을 확인했다.
- **자동 시작:** Pi 안전서비스 enabled/active 및 재부팅 뒤 active. GUI 자동 시작 파일은 등록됐지만 전 장치 연결 조건의 반복 화면 기동까지 완료한 것은 아니다.

## 해결 보류와 아직 남은 검증

- **전원/검은 화면:** 커널 저전압 기록이 있다. 같은 전원에서 USB 제거 뒤 화면 복구를 확인했지만 어댑터 교체나 전압 측정으로 원인을 확정하지 않았다. 제거 장치 목록과 센서 재연결 후 상태도 미확인이다. 추가 전원 해결 작업은 보류한다.
- **장착/판정:** IMU는 책상 시험 상태다. 최종 보행기 장착각 보정과 실제 사고 감지 성능 검증이 필요하다.
- **실제 SOS:** 공통 판정→문자→지도 경로는 모의 통합 검사로 확인했다. 실제 GUI SOS 클릭으로의 채널 수신은 아직 확인하지 않았다.
- **운용:** 전체 연결 상태의 반복 전원 기동·Wi-Fi 부재·인터넷 복귀·장시간 운용은 미완료다.

## 코드와 게시 상태

기능 변경은 PR #7~11에 반영됐으며 이 문서 작성 전 main 기준은 e2c453d다. 최종 코드 검증은 배포223개/독립 변경이 있는 원본236개 통과다. 이번 후속 게시 작업은 문서·선별 근거 화면만 갱신하며 장치 설정이나 외부 발송을 새로 수행하지 않는다.

비밀 URL·토큰·개인 설정은 장치에만 보관한다. 실제 위치 좌표는 이 공개 요약에서 제외했다.
