# `buttons.py`

> **한 줄:** 취소 버튼과 SOS 버튼. 고령자가 화면 팝업을 누를 것이라고 가정하지 않는다.
> **계층:** 입력 (안전 필수) | **의존:** `config`, `states`

---

## 왜 존재하는가

오경보가 났을 때 고령자가 **1280×720 화면의 팝업 버튼을 찾아 누를 것**이라고
가정해서는 안 된다. 손잡이에 붙은 큼직한 물리 버튼이 있어야 취소가 실제로 된다.

**취소 수단이 없으면 오경보 한 번으로 보호자의 신뢰가 무너지고,
그 시점부터 이 시스템은 무시당한다.**

## 버튼 2개

| 버튼 | 동작 | 명령 |
| :--- | :--- | :--- |
| 취소 | 짧게 누름 | `CMD_USER_NO` — 판정 취소 |
| SOS | **2초 이상 길게 누름** | `CMD_SOS` — 즉시 신고 |

**SOS는 `when_held` 만 연결한다.** `when_pressed` 를 쓰면 주머니에 눌려서
신고가 나간다. 짧게 누른 것은 의도적으로 무시한다.

## SOS의 의미

SOS는 판정 FSM을 **전부 건너뛴다.** 이유:

- 몸을 못 움직이지만 의식은 있는 경우
- 전도가 아닌 다른 응급 상황(현기증, 흉통 등)

**자동 감지만으로는 이런 상황을 절대 잡을 수 없다.**
또한 "사용자만 넘어지고 보행기는 서 있는 경우"(센서 배치의 근본 한계)에 대한
1차 보완 수단이기도 하다.

## 공개 인터페이스

```python
CMD_SOS = "sos"

class ButtonHub:
    def __init__(self, on_command, log_callback=None)
    def start(self); def stop(self)
```

`on_command` 는 보통 `TipoverMonitor.submit` 이다.

## 백엔드

| 이름 | 환경 | 비고 |
| :--- | :--- | :--- |
| `gpio` | Raspberry Pi | `gpiozero.Button`, `bounce_time` 으로 채터링 제거 |
| `keyboard` | 개발 PC | 터미널에 `n`(취소) `y`(확인) `s`(SOS) `r`(리셋) 입력 |
| `null` | 하드웨어 없음 | |

## 배선 (BCM)

버튼 한쪽 → GPIO 핀, 반대쪽 → GND. 내부 풀업 사용(`pull_up=True`).
기계식 스위치는 채터링이 있으므로 `BUTTON_BOUNCE_SEC` 로 걸러낸다.

## 고칠 때 주의

- ⚠ **SOS에 `when_pressed` 를 연결하지 말 것.** 위 이유 참조.
- ⚠ 콜백은 GPIO 인터럽트 스레드에서 호출된다. `TipoverMonitor.submit()` 은
  락으로 보호되어 있어 안전하지만, 다른 콜백을 붙일 때는 스레드 안전을 확인할 것.
- `keyboard` 백엔드는 `sys.stdin.isatty()` 가 참일 때만 활성화된다.
  systemd 환경에서는 자동으로 `null` 로 떨어진다.

## 미해결 (하드웨어 필요)

- **BOM에 버튼이 아직 없다.** 코드는 완성 상태이며 결선만 하면 된다.
- 안전 종료 버튼(전원 차단 전 OS 정상 종료)은 별도 회로가 필요하다.
  계획서 리뷰 §5.5 참조.
