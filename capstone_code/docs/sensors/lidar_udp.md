# `sensors/lidar_udp.py`

Jetson의 최신 장애물·단차 결과를 UDP 9100으로 받습니다.

설계 규칙:

- 최신값만 중요하므로 재전송 없이 UDP를 사용합니다.
- 수신 도착 시각으로 링크 신선도를 판정합니다.
- 링크가 끊기면 이전 거리값을 숨깁니다.
- 송신 세션 ID와 seq로 순서 역전·이전 세션 지연 패킷을 버립니다.
- `start()`는 멱등이며 무결성 검사와 초기화가 연속 호출해도 스레드는 하나입니다.

패킷 필수 필드: `v`, `seq`, `t`, `left`, `right`. 단차 필드 `curb_m`, `curb_type`은 선택입니다.

변경 시 중복 시작, 순서 역전, 재시작 수용, 링크 단절 테스트를 확인합니다.
