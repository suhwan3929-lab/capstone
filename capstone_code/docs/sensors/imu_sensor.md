# `sensors/imu_sensor.py`

> **한 줄:** EBIMU-9DOFV6 순수 드라이버. **판정 로직은 여기 없다.**
> **계층:** 센서 드라이버 | **의존:** `config`, `schema`, `states`, `pyserial`(선택)

---

## 무엇을 하는가

1. 시리얼에서 ASCII 한 줄을 읽어 파싱한다
2. 장착각 오프셋을 보정한다
3. 최신 샘플을 `ImuSample` 로 제공한다

그게 전부다. 전도 판정은 `tipover_monitor.py` 가 한다.
ROS 2 이행 시 이 모듈이 `imu_node` 가 되고 판정은 별도 노드가 된다.

## 공개 인터페이스

```python
snapshot() -> ImuSample              # 신선도 만료 시 valid=False로 강등
start(log_callback) -> bool
stop()
run_integrity_check(log_callback)    # 유효 데이터 수신까지 확인
capture_mount_offset(duration=2.0)   # → (roll, pitch) 평균
```

## 센서 설정

```python
SETUP_COMMANDS = ["<sof1>", "<sog1>", "<soa1>",
                  "<som0>", "<sod0>", "<sot0>", "<sots0>"]
EXPECTED_FIELDS = 9    # roll,pitch,yaw, gx,gy,gz, ax,ay,az
```

`<sof1>` 오일러각, `<sog1>` 자이로, `<soa1>` 가속도(중력 포함, g).
**나머지는 전부 끈다** — 켜져 있으면 필드 개수가 늘어 인덱스가 밀린다.

## 리팩터링에서 고친 것

| 결함 | 조치 |
| :--- | :--- |
| 예외 1회로 스레드가 죽고 재연결 없음 | 지수 백오프 감시 루프 (1→2→4→…→30초) |
| 데이터가 끊겨도 "정상" 표시 + 값 프리즈 | `t_capture` 기록 → `snapshot()` 이 신선도 만료 시 강등 |
| `len(parsed) < 9` (이하 배제) | `!= 9` 로 변경 — 필드가 늘면 인덱스가 조용히 밀린다 |
| 장착각 보정 없음 | `MOUNT_*_OFFSET_DEG` 적용 |

### 자체 진단 — 가장 중요한 안전장치

기동 후 50샘플의 평균 `accel_g` 가 1.0 ± 0.15 를 벗어나면 경고한다.

```
⚠ 정지 상태 가속도가 X.XXg (기대값 1.00g).
  필드 순서 / 단위 / 가속도계 측정범위(FSR) 설정을 확인하세요.
  FSR이 ±2g면 임계값 2.8g에 도달할 수 없습니다.
```

**FSR이 ±2 g / ±4 g로 설정돼 있으면 전도가 영원히 감지되지 않는다.**
이 진단이 그것을 조기에 잡는다.

## 고칠 때 주의

- ⚠ **`_parse()` 는 한 필드라도 숫자가 아니면 그 줄 전체를 버린다.**
  부분 파싱은 인덱스를 밀리게 하므로 의도적이다.
- ⚠ **필드 인덱스 가정(`parsed[0:3]`, `[3:6]`, `[6:9]`)은 `SETUP_COMMANDS` 에 종속적이다.**
  출력 항목을 바꾸면 인덱스도 같이 확인할 것.
- ⚠ `serial.Serial(..., dsrdtr=False)` — DTR 토글로 센서가 리셋되는 것을 막는다.
- `run_integrity_check()` 는 **포트 열기가 아니라 유효 샘플 수신**을 성공 조건으로 한다.
  케이블이 반쯤 빠져 있어도 USB-시리얼 칩만 살아 있으면 포트는 열린다.

## 미해결 (하드웨어 필요)

- ⚠ **가속도계 FSR 확인이 최우선 과제다.** 데이터시트에서 ±16 g 이상으로 설정할 것.
- **설정 저장(flash write) 명령이 시퀀스에 없다.** 전원 재인가 후 설정이 유지되는지 검증 필요.
- 계획서의 `<avca_e1>`(진동 제거)는 **감지하려는 충격도 함께 깎을 수 있다.**
  IMU 2개를 쓴다면 하나는 AVCA OFF로 두어 충격 전용 채널로 쓰는 것을 권한다.
