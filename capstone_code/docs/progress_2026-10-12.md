## 이 대화에서 진행한 내용

1. GitHub에서 받은 .py 파일은 편집기 대신 터미널에서 실행하도록 안내했다.
2. 기본 진입점은 run_dev.py이며, 정상 보행 시뮬레이션은
   `python run_dev.py --sim --scenario normal_walk --no-alert`다.
   화면 없는 SSH에서는 `--no-ui`를 추가한다. 실제 센서 검증과 구분한다.
3. PC는 유선 LAN, Pi는 Wi-Fi이고 Pi OS는 Ubuntu로 사용자 확인됐다.
   Raspberry Pi OS용 안내를 Ubuntu OpenSSH 설치 절차로 정정했다.
4. `ssh yu@192.168.0.173`의 `Connection refused`를 확인했다.
   Ubuntu에 openssh-server 설치·시작 후 서비스, 22번 포트, IP, 계정 확인을 안내했다.
5. 사진에서 unattended-upgrade 프로세스 13069의 APT 잠금과 대기 중인 SSH 설치를 확인했다.
   잠금 삭제/강제 종료 대신 진행 로그를 확인하도록 안내했다.
   이 대화의 후속 로그·설치 완료·SSH 재접속 성공 결과는 아직 없다.
6. 2026-10-12 GitHub fetch가 성공했고 `.publish-capstone`의 codex/powerbank-discord-safety / bfb0372는
   추적 브랜치와 0 / 0, 편집 전 변경 파일 없음으로 확인했다. main도 origin/main과 0 / 0이었다.
   파이의 fetch/status 결과는 미확인이다. 이번 문서 편집 후에는 로컬 문서 변경이 생겼다.
